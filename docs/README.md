# Technical documentation

- plan/: the unchanged submitted Part 1 DOCX and paragraph-text extraction.
- experiment_protocol.md: model assumptions, experimental design, actual deviations and preservation requirements.
- decisions.md: codebase choices, rationale, consequences and verification status.
- presentation_alignment.md: current v3 content mapped to implementation and canonical evidence paths.
- visual_plan.md: source-backed diagrams and charts for a possible later deck version.
- reference_manifest.json: original implementation and artifact hashes.
- relocation_checks.json: exact moved paths and preservation checks.
- simulator_validation.md and controller_validation.md: extraction checks and their limits.
- full_reproduction_validation.md and full_reproduction_checks.json: full-budget artifact comparisons and runtime differences.
- implementation_gates.md: actual staged implementation and commit record.
- references.md: scholarly publication references.

Historical stage checks are retained as dated records; they do not replace the completed full-reproduction evidence. Recording, instructor access, publication and submission remain separate from code and experiment verification.
